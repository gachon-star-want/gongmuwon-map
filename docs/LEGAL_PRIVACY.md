# LEGAL_PRIVACY — 법적 근거 + 표기 정책 + 면책 조항

## 결론 한 줄

**원본 데이터는 법령에 의해 의무 공개되었고, 공공누리 제1유형 라이선스로 상업적 이용·변형까지 허용된다.** 우리 서비스는 이를 가공·재공개하므로 적법하지만, 운영상 민원 리스크를 최소화하는 표기 정책을 따로 박는다.

## 법적 근거 4겹

### 1. 「공공기관의 정보공개에 관한 법률」 제9조 1항 6호

| 원칙 | 단서 |
|---|---|
| 개인에 관한 사항으로 사생활 침해 우려가 있는 정보는 비공개 | **가목**: "**직무를 수행한 공무원의 성명·직위**"는 **공개 대상의 예외** |

→ 공무원의 직무 행위(업무추진비 집행)에서 성명·직위는 명문 공개 가능.

### 2. 「지방자치단체 업무추진비 집행에 관한 규칙」 + 행안부 **「업무추진비 집행내역 공개기준」(별표 6)**

의무 공개 항목:
- 집행일시
- 집행장소(식당명·주소)
- 집행목적
- 집행대상(직급·인원)
- 집행금액
- 결재방법

→ 우리가 사용하는 모든 필드가 법령상 의무 공개 항목.

### 3. 「공공누리 제1유형」

서울 열린데이터광장 등 공공기관 데이터 라이선스:
- 출처표시 시 **상업적 이용 가능**
- **변형·2차 저작물 작성 가능**
- 별도 허가 불필요

→ 우리 서비스(가공·재공개·광고 모델)에 적용 가능.

### 4. 사실 적시 명예훼손과 위법성 조각 (형법 310조)

판례 흐름 (대법원 95도1473 등):
- 진실한 사실 + 공공의 이익이면 위법성 조각.
- "공무원으로서 국가의 정책 방향을 정하는 지위 + 활동이 일정 지역사회·국가적 관심사" → 공인 지위, 공공의 이익 인정.
- 헌법재판소도 형법 307조 1항의 위헌소원 기각, 다만 사실 적시는 신중해야.

→ 우리 데이터(공식 공개 정보의 재공표)는 위법성 조각 강력 적용. **단 사용자 댓글·평가는 별개**, v1엔 미적용.

## 우리 표기 정책 (개인정보위 균형 판단 응용)

법령상 모두 공개 가능하지만, 개인정보위가 "총체적 프로파일링"으로 균형 판단하는 점을 고려해 **운영 안전선**을 다음과 같이 박는다:

| 대상 | 표기 | 이유 |
|---|---|---|
| **선거직 고위공무원** (시장·구청장·시의원·구의원) | **실명 + 직급** | 판례상 공인 지위, 지역 관심사. 후보등록·재선 활동의 일부. |
| **임명직 고위공무원** (부시장·실장·국장·과장) | **직급 + 부서**, 실명 마스킹 | 공인 지위 약화, 직급으로도 사실상 식별 가능하므로 추가 안전판. |
| **5급 이하 일반직** | **부서명**, "○○과 외 N명" | 식별성 최소화. |
| **민간인 동석자** (간담회 등) | **마스킹**, "민간 외 N명" | 비공무원 보호. |
| **식당명·주소·일자·금액·인원수·목적·결재방법·비목** | 그대로 표기 | 법령상 의무 공개. |

### 마스킹은 어디서

- **데이터 적재 단계(LLM 정규화)** — DB에 절대 평문 저장 금지.
- 마스킹 검증은 schema validator로 한 번 더 — 실명 패턴(2~4자 한글)이 `representative` 외 컬럼에 들어가면 reject.
- 상세는 [PIPELINE.md](PIPELINE.md#마스킹-룰).

## 사용자 권리 (개인정보보호법 + 정통망법)

### 정보 수정·삭제 요청 (`/r/{id}` 디테일 패널 → 모달)
- 식당 사장님: "우리 식당 정보 빼주세요"
- 공무원: "내 직급·부서 노출 빼주세요"
- 일반 시민: "이 정보가 잘못됐어요"

처리 흐름:
1. **요청 즉시 자동 hide** (`places.hidden_at = now()` 또는 visit 단위)
2. **운영자 72h 내 검토**
3. 합당: 영구 삭제 또는 부분 마스킹 강화
4. 불합당: 복원 + 이메일로 사유 통보

### 폐업 신고
3건 누적 시 `is_closed = true` 자동 처리, 모더레이션은 v1.1.

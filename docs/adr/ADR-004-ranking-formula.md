# ADR-004 — 등급 공식: 횟수 × 부서 다양성 + 자치구별 백분위

- **Status**: Accepted
- **Date**: 2026-05-23

## Context

"공무원이 자주 가는 진짜 맛집"의 시그널을 어떻게 점수화할 것인가. 옵션:

1. **단순 방문 횟수** — 직관, 다만 한 부서 단골 = 여러 부서 공통과 구분 안 됨
2. **횟수 × 부서 다양성**
3. **횟수 × 부서 × 직급 가중**
4. **시간 감쇠 + 위 가중치**

또한 등급 컷오프를 **절대값** vs **백분위**로 할지 결정 필요.

## Decision

**점수 = `visit_count_12m × log10(unique_department_count_12m + 1)`**

**등급 = 자치구별 백분위 컷오프**
- ★★★ 강추: 상위 10% (`pct ≥ 0.90`)
- ★★ 추천: 상위 30% (`0.70 ≤ pct < 0.90`)
- ★ 중립: 상위 60% (`0.40 ≤ pct < 0.70`)
- ✦ 신규: visit ≤ 2 AND first_visit ≥ 3개월 전 (별도 트랙)

자치구별 식당 < 30이면 전체 서울 분포로 fallback.

## Consequences

- "광고 시그널"과 가장 다른 차별점: **부서 다양성 가중**으로 "공통 픽" 식당 부각.
- 자치구별 백분위 → 강남·도봉 같은 격차 보정.
- 데이터 누적되면 6개월 후 절대값 lock 가능.
- UI에선 백분위 → 절대값 환산 함께 표시 ("이 자치구 상위 8% · 12회·5개 부서").

## Alternatives Considered

- 직급 가중치: LLM 마스킹 정확도가 검증되어야 함. v1.1로 미룸.
- 시간 감쇠: 단순화 위해 12개월 균등. v1.1 A/B 검토.

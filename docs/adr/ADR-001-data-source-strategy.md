# ADR-001 — 데이터 소스 전략

- **Status**: Accepted
- **Date**: 2026-05-23

## Context

전국 지자체 업무추진비를 단일 정형 데이터로 합치려면, 어디서 어떤 형식으로 가져올지 결정해야 한다. 옵션:

1. **서울시 정보소통광장** (`opengov.seoul.go.kr/expense`) — HTML 표, 식당명+주소 한 줄로 노출. 본청+사업소 포함.
2. **서울 열린데이터광장** (`data.seoul.go.kr/dataList/OA-22156`) — CSV/OpenAPI, 공공누리 1유형. 다만 "서비스 종료" 안내가 보임.
3. **자치구청·의회 게시판** — PDF/HWP/XLSX 첨부. 양식 제각각.
4. **행정안전부 표준 양식 게시 채널** — 컬럼은 같지만 다운로드 절차가 까다로움.

## Decision

**1번을 메인 소스로, 3번을 보조로 채택.** 2번은 백업 검증용.

- **서울시청·서울시의회**: 정보소통광장의 본청 + 사업소 항목.
- **25개 자치구청 + 25개 자치구의회**: 각 기관 게시판 첨부 파일.
- **메인 추출 경로**: 첨부 파일 → 텍스트화 → LLM 정규화.

## Consequences

- 데이터 형식이 통일되지 않으므로 [ADR-002](ADR-002-llm-extraction.md)와 묶여서 결정됨.
- 정보소통광장이 가장 풍부(수만 건) → ROI 큼.
- 자치구·의회는 분량 작아 LLM 비용 부담 적음.
- 「업무추진비 집행내역 공개기준」(별표 6)으로 컬럼 표준화 → 추출 일관성 확보 가능.

## Alternatives Considered

- 정부24 정보공개청구 API: 지연 길고 자동화 어려움. Reject.
- 자치구별 hand-coded 어댑터 50개: 시간 비용 + 유지보수 부담. Reject.
- 행안부 단일 채널만: 자치구별 게시 누락·지연 많음. Reject.

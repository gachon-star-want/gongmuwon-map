# PRD — 공무원맵 (Public Officer Map)

## 한 줄 정의

전국 지자체가 법령에 의해 의무 공개하는 「업무추진비 집행내역」을 자동 수집·정제하여, **공무원이 자주 가는 식당**을 지도에 등급별로 표시하는 시민 서비스.

## 왜 만드는가 — 문제와 가설

### 사용자 문제
- 한국의 음식점 추천 서비스(네이버 플레이스·카카오맵·망고플레이트·다이닝코드 등)는 **사업자가 광고하는 정보**가 시그널을 왜곡한다.
- 진짜 신뢰할 수 있는 식당은 결국 "지역의 일을 잘 아는 사람이 반복적으로 가는 집"이다.
- 공무원의 업무추진비는 법령에 의해 **일시·장소·목적·대상·금액**이 의무 공개되지만, 흩어져 있어 데이터로 활용되지 않는다.

### 가설
- 공무원이 12개월 안에 여러 부서가 공통으로 반복 방문하는 식당은 **광고 시그널이 아닌 실사용 시그널**이다.
- 이 데이터를 지도 + 등급으로 정제하면 **광고가 망친 한국 식당 추천 시장의 노이즈를 우회**할 수 있다.

### 비유사 선례
- [cham-monimap.com](https://cham-monimap.com) — 대전참여자치시민연대 운영, 대전 권역 한정, 시민단체 색채.
- [kofficer-guide.co.kr](https://www.kofficer-guide.co.kr) — 상업 운영(AdSense), 콘텐츠 큐레이션 중심, 알고리즘 정밀도 낮음.
- 우리는 두 선례 **사이 포지션**: 서울 전체+의회 포함, 부서 다양성 기반 등급, AI 에이전트용 API까지 노출.

## 누구를 위한 서비스인가

| 페르소나 | 사용 시나리오 |
|---|---|
| **지역 직장인** | "오늘 점심 회식 어디로 잡지" — 자치구 + 등급 ★★★로 필터 |
| **출장·관광객** | "이 지역에 오면 어디 가야 진짜인가" — 자치구 외부에서 자치구 검색 |
| **시민 감시·기자** | 특정 기관·부서의 식당 사용 패턴 분석 |
| **데이터 분석가** | 공개 API를 통해 정형 데이터 수집 |
| **AI 에이전트** (Claude·ChatGPT 등) | `/api/v1/places` + `/llms.txt`로 안전한 데이터 인용 |

## v1 스코프 (오늘 설계, 추후 구현)

### 데이터 범위
- **서울 — 52개 기관**: 서울시청(1) + 서울시의회(1) + 25개 자치구청 + 25개 자치구의회
- **시간 윈도우**: 최근 12개월(rolling) — 등급 계산
- **백필**: 최근 24개월 데이터 보관 — 미래 분석용
- **갱신 주기**: 매일 1회

### 사용자 기능 (v1)
- ✅ 지도에서 등급별 마커로 식당 찾기 (★★★ 강추 / ★★ 추천 / ★ 중립 / ✦ 신규)
- ✅ 자치구·기관 유형(시청/의회/자치구청/자치구의회) 필터
- ✅ 식당 상세: 방문 부서 목록, 방문 횟수, 최근 방문일, 평균 인당 금액
- ✅ 원문 PDF/HTML 링크로 검증 가능
- ✅ "정보 삭제 요청" 익명 폼 + 운영자 이메일
- ✅ "폐업 신고" 익명 신고 (3건 누적 시 자동 폐업 라벨)
- ✅ 공개 REST API + OpenAPI + llms.txt
- ✅ 별도 커뮤니티 게시판: 열람 공개, 글·댓글 작성은 로그인 필요
- ✅ 식당 상세의 로그인 기반 좋아요/싫어요 반응

### v1에 **없는** 것 (의도적 배제)
- ❌ 식당/좌표 상세에 사용자 댓글·평점·후기 부착 — 명예훼손 리스크
- ❌ 음식 카테고리 자동 분류 — 데이터 신뢰도 부족
- ❌ 회원 가입 강제 — 익명 사용 우선
- ❌ 모바일 네이티브 앱 — PWA로 대체

## 비기능 요구사항

- **법적 안전**: 모든 표기는 `LEGAL_PRIVACY.md` 정책에 부합. 위반 시 머지 금지.
- **데이터 출처 투명성**: 모든 식당 카드에서 원문 링크 제공.
- **접근성**: WCAG 2.1 AA — 키보드 내비게이션, 명도 대비, 스크린리더 라벨.
- **검색 가능성(SEO)**: 자치구·식당별 정적 페이지 + sitemap.xml + JSON-LD.
- **LLM 친화성**: `/llms.txt` + `/llms-full.txt` + OpenAPI 3.1 스펙.

## 의도적 비목표 (Non-Goals)

- **민원·고발 채널이 아니다.** 공무원 비위 의심 표현·라벨링 금지.
- **맛집 평가가 아니다.** 우리는 "자주 가는 곳" 시그널만 노출. "맛있다"고 단정하지 않음.
- **모든 식당 DB가 아니다.** 공무원이 방문하지 않은 식당은 우리 DB에 없음.

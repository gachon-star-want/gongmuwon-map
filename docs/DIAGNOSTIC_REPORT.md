## 2. 지역 불일치 (True Mismatch)

중앙부처(NON_REGION)를 제외한 기관-식당 지역 불일치: **3,532건 / 30,000건 샘플 기준 11.8%**

### Worst pairs

| 기관 지역 | 매칭된 식당 지역 | 방문 수 |
|-----------|----------------|--------:|
| 인천 | 서울 | 2,382 |
| 대전 | 서울 | 779 |
| 경기 | 서울 | 133 |
| 서울 | 경기 | 50 |
| 대전 | 인천 | 18 |
| 충북 | 충남 | 11 |
| 경기 | 충남 | 8 |
| 충북 | 강원 | 8 |

### 인천→서울 2,382건 분석
인천-서울은 인접하기 때문에 일부는 정당할 수 있음. 그러나 address_hint 없이 Kakao 검색이 기본적으로 서울 지역을 우선 반환하는 bias가 큰 원인으로 추정. 실제 오매칭 비율은 더 세밀한 분석 필요.

### 대전→서울 779건 (확실한 오매칭)
대전에서 140km 떨어진 서울의 식당이 매칭된 사례. 이슈 제보자가 원래 지적한 문제와 일치. Kakao 검색이 address_hint 없이 "메가커피" 같은 체인명만으로 검색될 때 서울 지점을 반환하는 패턴.

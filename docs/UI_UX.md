- 좌측 목록 패널: 342px 내외, 목록 버튼으로 열고 닫음

식당 상세에는 사용자 자유 텍스트 댓글·후기·별점이 붙지 않는다. 좌표/식당 단위 사용자 표현은 좋아요·싫어요 집계만 허용한다.

## 커뮤니티

- `/community`는 식당 좌표와 분리된 별도 게시판이다.
- 열람은 누구나 가능하다.
- 게시글 작성과 댓글 작성은 로그인 후 가능하다.
- 커뮤니티 글은 특정 식당의 공식 등급, 방문 기록, 지도 좌표에 결합하지 않는다.
- 식당 상세 댓글·평점·후기처럼 보이는 UI는 만들지 않는다.

## 로그인

- 닉네임 + 비밀번호 기반 경량 로그인.
- 세션은 HttpOnly 쿠키로 보관한다.
- 로그인은 커뮤니티 작성과 식당 좋아요/싫어요 반응에만 필요하고, 지도 열람은 익명으로 가능하다.

## 광고

- 데스크톱 지도: 우측 레일형 배너를 기본 후보로 사용하되, 상세 패널이 열리면 상세 패널을 우선한다.
- 목록/상세 패널: 하단 인라인 배너.
- 모바일: 지도 위 고정 광고는 피하고, 목록/상세 바텀시트 내부 하단에 배치한다.
- 광고는 지도 조작, 출처 표시, 삭제 요청 버튼을 가리지 않는다.

## 빈 상태

| 상황 | 표시 |
|---|---|
| 첫 진입 | 서울 전체 줌 + 필터 디폴트 |
| 필터 결과 0건 | "조건에 맞는 식당이 없습니다. 필터를 조정해 보세요." + 필터 리셋 버튼 |

## 신고 폼

### "폐업 신고"
- 모달
- 단순 확인 버튼 + 선택 사유(드롭다운: "방문해보니 폐업", "다른 가게 입점", "장기 휴업")
- 익명 fingerprint 자동 수집(localStorage 토큰)
- 같은 토큰 중복 신고 자동 차단 (서버에서도)

### "정보 수정·삭제 요청"
- 모달
- 라디오: ① 식당 정보 오류 / ② 방문 기록 오류 / ③ 본인·소속 정보 노출 우려 / ④ 기타
- 자유 텍스트 (필수, 50자 이상)
- 이메일 (선택, 응답 받으려면 권장)
- 제출 → 즉시 hide → 운영자 검토 메시지 노출

## 접근성

- WCAG 2.1 AA
- 키보드: Tab으로 필터·마커·디테일 패널 모두 도달
- 명도 대비: 텍스트 4.5:1 이상
- 스크린리더: 마커는 `aria-label="강추 등급, 창고43 시청점, 서울 중구"`
- 모션 감소: `prefers-reduced-motion` 존중

## SEO

- SPA지만 `index.html`에 base 메타태그 + path별 JS 동적 주입 (거지맵 패턴)
- 식당 상세 페이지(`/r/...`)는 정적 사이트맵에 모두 포함
- 자치구 페이지는 별도 정적 페이지 (`/agency/...`)
- JSON-LD `Restaurant` 스키마 식당 페이지마다 주입
